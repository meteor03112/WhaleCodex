Agent 安全
Agent 只能在这些目录内读写；越界会被直接拒绝。留空时由程序选择默认工作目录。点 📂 可自主选择目录并自动迁移该目录下的工作数据。

一键自检
一次跑完引擎配置、密钥隔离、沙箱执行器、打包完整性、目录白名单、快照还原、审计、适配层、工具路由、上游连通与最近异常。
Agent 引擎
Codex 引擎会按模型名决定是否下发工具。实测 gpt-6-astra 这类名字会被判成「不支持工具」，Agent 因此拿不到命令执行能力；这里显示当前模型交给引擎时实际使用的名字。
Agent 兼容生态（模型 × 工具协议）
适配层按模型自动选择「原生工具调用」或「结构化文本协议」，并在运行时自学习；遇到不支持 tools 的端点会自动降级，无需手工配置。
